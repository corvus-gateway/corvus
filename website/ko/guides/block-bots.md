# 셀프 호스팅 사이트에서 악성 봇과 취약점 스캐너 차단하기

공개된 서버의 접근 로그를 보면 요청의 대부분은 사람이 아닙니다. 크롤러, 가동 상태 확인 도구, AI
스크래퍼, 그리고 사이트에 있었던 적도 없는 경로를 시도하는 스캐너입니다.

## 어떻게 보이나요

| 종류 | 전형적인 요청 | 피해 |
|---|---|---|
| 취약점 스캐너 | `/.env`, `/.git/config`, `/wp-login.php`, `/phpmyadmin/`, `/cgi-bin/`, 쿼리 문자열에 담긴 공격 페이로드 | 패치되지 않은 앱이나 유출된 파일을 찾아냄 |
| 무차별 대입 | IP 하나 또는 몇 개에서 오는 수백 건의 `POST /login` | 비밀번호 추측 |
| 스크래퍼 | 수천 건의 페이지 요청, 흔히 일반적이거나 가짜인 User-Agent 사용 | 부하, 콘텐츠 복제 |
| 대량 요청 | URL 하나에 초당 많은 요청 | 사이트가 느려지거나 접속 불가 |

좋은 크롤러(검색 엔진, 내 모니터링)는 문제가 아닙니다. 목표는 이들을 막지 않으면서 나머지를
멈추는 것입니다.

## 가벼운 것부터 엄격한 것까지, 다섯 단계

1. **공격 경로와 페이로드를 차단합니다.** `/.env`를 요청하거나 `../../etc/passwd`가 들어 있는
   요청은 정상일 수 없습니다. 바로 차단하세요. 이것만으로도 스캐너 트래픽 대부분이 사라집니다.
2. **반복하는 IP를 차단합니다.** 몇 분 사이에 차단이나 `404`를 많이 일으키는 IP는 스캐너입니다.
   일정 시간 차단하고, 다시 올 때마다 더 오래 차단하세요.
3. **민감한 경로에 Rate Limit을 겁니다.** 사람에게는 IP당 분당 몇 번의 로그인 시도면 충분합니다.
4. **User-Agent, IP 목록, 국가로 걸러 냅니다.** 방문자층에 맞는 곳에 적용하세요. 알려진 악성 봇
   User-Agent, Tor 출구 노드, 커뮤니티 차단 목록, 서비스 대상이 아닌 국가 등입니다. 기록만 하는
   모드로 시작해 무엇이 차단될지 먼저 확인하세요.
5. **남은 것에 챌린지를 겁니다.** 브라우저 챌린지(짧은 JavaScript 계산이나 쿠키 확인)는 실제
   브라우저를 쓰지 않는 클라이언트를 CAPTCHA 서비스 없이 막습니다. 로그인 페이지에 쓰거나, 공격을
   받는 동안 사이트 전체에 쓰세요.

브라우저가 아닌 클라이언트를 잊지 마세요. 앱, API 클라이언트, 피드 리더, 모니터링은 챌린지를 풀
수 없습니다. 이들의 경로나 IP는 예외로 두세요.

## Corvus로 하기

[Corvus](../index.md)에서는 이 단계들이 스크립트가 아니라 설정입니다.

| 단계 | 설정 위치 |
|---|---|
| 공격 경로와 페이로드 | 새 호스트마다 켜져 있음: 프록시 호스트 → *보호* ([동작 방식](../security/index.md)) |
| 반복하는 IP 차단 | [자동 차단](../security/bans.md#automatic-bans), 404 폭주에는 *스캐너 의심 IP도 차단* |
| Rate Limit | [호스트별](../security/bans.md#rate-limits) |
| User-Agent, IP 목록, 국가 | [보안 규칙](../security/rules.md)과 [목록](../security/ip-lists.md), 악성 봇 User-Agent와 Tor 출구 노드 프리셋 제공 |
| 챌린지 | [챌린지 규칙 또는 공격 대응 모드](../security/challenge.md), 외부 서비스 불필요 |

[트래픽 관제](../operations/traffic.md)는 차단마다 그 이유를 보여 주므로 오탐을 확인할 수 있고,
[알림](../operations/alerts.md)은 반복되는 공격 출처를 알려 줍니다.

## Corvus 없이 하기

순수 nginx로도 경로와 User-Agent에는 `map` 블록, Rate Limit에는 `limit_req`, 그리고 접근 로그를
읽는 fail2ban으로 꽤 많은 것을 할 수 있습니다. CrowdSec은 커뮤니티 차단 목록과 여러 프록시용
바운서를 더해 줍니다. 관리할 조각이 늘어나지만 동작합니다.
[Corvus와 다른 리버스 프록시 비교](../compare/index.md)를 참고하세요.
